# Using the Overview page

The Overview page is what you see when you open Santa Clara Health Intelligence. It's meant to answer three questions in under a minute: what is this, why should I care, and what can I do here.

## What's on the page

**The headline and task cards.** Three starting points, each pointing at something you can actually do right now:
- **Explore a community** — search a city, district, or census tract and see its health, access, and resource picture.
- **See where concerns overlap** — jump straight to the full countywide ranking, as a table.
- **Compare two places** — go to Explore with the comparison panel already open.

**Countywide snapshot.** A small number of real, current numbers — how many tracts currently show high combined concern under the default scenario, how many of those rankings are stable versus assumption-sensitive, and how many tracts have too little data to score confidently. This is deliberately not a wall of statistics; it's picked to be decision-relevant at a glance, with a link to see the full picture in Explore.

**Where might action be most urgent?** The top three tracts under the default scenario's priorities, each with its stability label and score, and a link to see the full ranking or change which priorities are weighted. This is a screening-priority ranking under one set of assumptions — not a certainty, and the page says so.

**Data status.** How many data sources this platform tracks, whether any are due for a refresh or currently unavailable, and a link to the full Data page where you can see every source's publisher, vintage, and license.

**How to read what this platform shows you.** Five short statements that matter more than they might look: this platform uses only public data, never anything at the individual level; every score's method is visible; uncertainty is shown, not hidden; and a high score is a signal to look closer, not proof that any specific program would fix anything.

## What the Overview page is not

It's not a dashboard you're meant to read every number on. It's meant to get you to the right next step — almost everything on it is a link into Explore, where the real detail lives.

## If something looks wrong

If a number seems stuck loading or shows an error message, check the Data page — it will tell you honestly whether a source is temporarily unavailable rather than showing a wrong number silently. If the whole page won't load, the backing service may be down; there's nothing to configure on your end.
