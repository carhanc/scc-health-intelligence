# Using the Explore page

Explore is where you find a specific place — a city, a supervisor district, a ZIP-code area, or an individual census tract — and see its health, access, and resource picture in detail.

## Finding a place

Type into "Find a place." You do not need to know a census tract number to get started — search:
- A city or town name ("Sunnyvale," "San Jose")
- A ZIP code ("95128") — matched to its ZIP Code Tabulation Area (ZCTA), the Census Bureau's own approximation of that ZIP code's boundary, which is not always identical to the real ZIP code
- A supervisor district, by number or supervisor name ("District 3," "Otto Lee")
- A census tract number, the 11-digit identifier the U.S. Census Bureau assigns to each tract (e.g. "06085500100") — still fully searchable, just no longer first in line for a query that looks like a city, ZIP, or district

Search results show the type of place and its name; for a tract result, the number is shown alongside the name so you can confirm you found the right one. City, ZIP, and district results are shown ahead of tract matches for the same search term, so a common city name is never buried behind a long list of tract numbers. Click a result to select it.

## The map and the table

By default you see a map of the county, shaded by combined concern score under the current priorities — darker teal means higher concern, and tracts with no score for the current priorities are shown in a distinct neutral color, never left looking like a real low score. Click any tract to select it.

If a city, district, or ZIP-code area is selected, the map pans to it and draws a dashed outline so you can see exactly where it is and click a tract inside it — scores are calculated per census tract, not for a whole city or district at once, since a city can contain tracts with very different pictures. The panel on the right also lists that city or district's highest-concern tracts directly, so you can jump straight to one without hunting on the map.

Prefer not to use the map, or want every tract's numbers in one sortable list? Switch to Table using the control above the map. It's the same underlying data, sortable by any column, fully usable with a keyboard — click a column header to sort, click or press Enter on a row to select that tract.

## Reading a tract's profile

Once you select a tract, the panel on the right shows:

**A plain-language summary** — one sentence stating whether this tract shows high, moderate, or lower combined concern under the current priorities, and which factor is driving that most.

**The score** — a 0-100 combined concern score, a badge telling you whether that ranking is stable or sensitive to assumptions (hover or focus the badge for an explanation), the likely range accounting for uncertainty, and the tract's rank out of all 408 tracts countywide. A note underneath always reminds you this is a screening score, not a prediction — it flags a tract for a closer look, it doesn't claim any specific program would fix it.

**What's driving this score** — click any domain (Health burden, Access barriers, Environmental burden, Resource accessibility, Workforce shortage) to expand it and see the individual measures behind it: the raw value, how it compares to the rest of the county, a plain-language explanation of what it measures, and any known limitation.

**View sources & evidence** — opens a panel listing every measure used in this score, its exact value for this tract, and its publisher and vintage, so every number is traceable to a real source.

## Changing priorities

The "Priorities" dropdown near the top switches which scenario's weighting is applied — for example, "Balanced overview" weighs every factor equally, while "Diabetes prevention" weighs health burden and access barriers more heavily. Changing it updates the description text, the score, and the ranking immediately; nothing is hidden behind a separate "apply" step.

## Comparing two places

With a tract selected, click "Compare." A second search box appears — find another tract (comparisons work tract-to-tract, since scores are calculated at that level) and select it. You'll see both scores side by side, a plain-language statement of which one is higher and by how much, whether their uncertainty ranges overlap enough that the difference might not be meaningful, and a domain-by-domain breakdown.

## Sharing what you found

Everything you select — the place, the priorities, whether you're viewing the map or table, and an open comparison — is saved in the page's web address. Copy the address bar to share exactly what you're looking at, and your browser's back and forward buttons move between your previous selections as you'd expect.

## If a place doesn't load

If you land on a page with an identifier that doesn't match any real tract, you'll see a plain explanation of what didn't load, a button to retry, and a button to clear the selection and start over — never a raw error code as the main message.
